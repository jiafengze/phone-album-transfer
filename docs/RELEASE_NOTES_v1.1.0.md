## 最重要的变化：不开 USB 调试也能用了

之前必须先开 USB 调试才能用，这一步劝退了不少人。现在加了 **MTP 兜底模式**——插上线、选「传输文件」、打开程序，就能直接浏览和传输。

程序会**自动选择**模式，不需要手动切换。

| | ADB 模式 | MTP 模式（新增） |
|---|---|---|
| 前提 | 需开启 USB 调试并授权 | **只需插线选「传输文件」** |
| 速度 | ~37 MB/s | ~28 MB/s |
| 拍摄时间 | ✅ 准确 | ❌ 显示「未知」 |
| 分辨率 / 时长 | ✅ 有 | ❌ 无 |
| 相册分组 | 与手机图库完全一致 | 按文件夹，基本一致 |

ADB 可用时走 ADB，不可用时自动降级到 MTP，两条路都能完成传输。

## 其他改进

- 修复：MTP 模式下时间列显示 `1970-01-01` 的问题，改为「未知」
- 窗口标题会标明当前模式（`手机相册传输 — MTP 模式`）
- 新增 `--mtp` 参数，可强制走 MTP 模式
- 新增 `--selftest` 自检参数，用于验证 MTP 传输链路

## 已验证

MTP 模式在华为 P60 Pro 上实测：识别 43 个相册，单文件传输 **218,325 字节字节级一致**，用时 0.33 秒。相册数量与文件大小和 ADB 模式完全吻合。
