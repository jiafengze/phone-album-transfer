## 你能看见自己正在用哪种模式了

之前模式只体现在标题栏后缀上，不明显。现在：

**状态栏右下角常驻一个彩色标识**

| 显示 | 含义 |
|---|---|
| ● **ADB 模式**（绿色） | USB 调试通道，快、信息全（有拍摄时间、分辨率） |
| ● **MTP 模式**（橙色） | Windows 文件传输通道，慢一点、时间显示"未知" |

鼠标悬停还能看到该模式的说明。标题栏也会同步显示 `— MTP 模式` 后缀。

## 用着用着想去开 USB 调试？不用重启

这是这版的重点。以前你在 MTP 模式下想去开 USB 调试，只能关掉程序、开完再重开。

现在 MTP 模式下，工具栏最右边会多出「**切换到 ADB 模式**」按钮：

1. 点它 → 程序先检测一次
2. 连不上 → 弹对话框，把开启步骤列出来（8 个品牌路径都写在 README 里）
3. 你照着在手机上开完，回来点「**重试**」
4. 检测通过 → 自动切成 ADB 模式并重新读取清单

**全程不需要关闭程序。** 对话框会显示是第几次检测，失败时还会给出针对性提示（该点允许？该换线？该点「修复连接」？）。

## 刷新清单现在会重新探测

点「刷新清单」时，程序会优先尝试 ADB——连得上就用 ADB，连不上才退回 MTP。所以这也是一个隐式的"升级"入口。

## 已验证

在华为 P60 Pro 上实测：

- **MTP 模式**：标题 `手机相册传输 — MTP 模式`，状态栏橙色 `● MTP 模式`，工具栏出现「切换到 ADB 模式」，时间列显示「未知」
- **ADB 模式**：标题 `手机相册传输`，状态栏绿色 `● ADB 模式`，切换按钮自动隐藏，时间列显示真实拍摄时间

## 一个小提示

MTP 模式和 ADB 模式列出的文件数量可能略有差异（本次实测 4065 vs 3936）。

原因是：**ADB 模式读的是 MediaStore 索引**，MTP 模式**直接遍历文件夹**。如果系统索引没有及时更新（比如文件被移动过），MTP 反而会看到更多文件。两个数字都对，只是口径不同。
