首个发布版本。

## 功能

- **按手机相册的视图浏览**：直接读取 Android MediaStore，分组和你的手机图库完全一致（相机 / 截屏 / 录屏 / 各 App 目录 / 自建相册）
- **文件列表**：文件名、类型、大小、**拍摄时间**、分辨率、时长，点击列头可排序
- **选择性传输**：右键相册传整个相册，或多选文件只传所选
- **实时进度**：速度、剩余、可中途取消
- **增量跳过**：已存在且大小相同的自动跳过，可反复点
- **按相册分目录**保存，中文相册名/文件名正常处理

## 下载

下载下面的 `PhoneAlbum-v1.0.0-win64.zip`（4.24 MB），解压到任意目录，双击 `PhoneAlbum.exe`。

**已内置 adb**，不需要自己装 platform-tools。

## 环境要求

- Windows 10 1903+ / Windows 11
- .NET Framework 4.8（系统自带）
- 手机端开启「USB 调试」

## 首次使用

1. 手机上开启 USB 调试：设置 → 关于手机 → 连点「版本号」7 次 → 系统和更新 → 开发人员选项 → 打开 USB 调试
2. 插数据线，通知栏选「传输文件」，手机上点「允许 USB 调试」
3. 双击 `PhoneAlbum.exe`

若程序提示「没检测到手机」但设备管理器里 ADB Interface 状态正常，双击包内的 `修复ADB连接.bat`（需管理员），它会补上 Windows 通用驱动缺失的 adb 接口 GUID。

## 已知限制

- 只读取共享存储中的媒体索引，看不到 App 私有目录里的文件
- 微信聊天中未「保存到手机」的图片不显示
- 暂不支持无线传输

详见 [README](https://github.com/jiafengze/phone-album-transfer#readme)。
