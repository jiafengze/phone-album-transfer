# 手机相册传输 · PhoneAlbum

在电脑上**按手机相册的视角**浏览照片和视频，勾选需要的再传，不用等全量同步跑完。

> Windows 11 / 10 · 单文件绿色版 · 无需安装 · 内置 adb

![界面截图](docs/screenshot.png)

---

## 为什么做这个

想把手机上的一批照片弄到电脑，常见做法是按文件夹翻。但手机里的文件长这样：

```
1745810346100.jpg                 ← 时间戳，但没人读得出来
tb_image_share_1756690866598.jpg.png   ← 双扩展名
Image_446158920605739.jpg         ← 随机 ID
IMG_20261021_155747_1.jpg         ← 同秒重名
```

而 **Windows 资源管理器通过 MTP 看手机时，连时间都是错的（显示 1899 年）**，更没有"相册"这个概念。

所以这个工具换了思路：不去扫文件系统，而是直接读 Android 的 **MediaStore** —— 手机图库自己用的那份媒体索引。

---

## 功能

**左侧相册树**

- 和手机图库**同样的分组**：相机 / 截屏 / 录屏 / 各 App 目录 / 你自建的相册
- 每个相册标注 `数量 · 体积`，按文件数排序
- 顶部有「全部 / 全部图片 / 全部视频」的汇总节点

**右侧文件列表**

- 文件名 · 类型 · 大小 · **拍摄时间** · 分辨率 · 时长
- 点列头排序（按时间、按大小、按文件名）

**传输**

- **右键相册** → 传输整个相册
- **多选文件** → 传输所选（Ctrl / Shift / Ctrl+A）
- 实时进度条 + 速度 + 可中途取消
- 自动按相册分子目录保存
- **跳过已存在且大小相同的文件**，可以反复点，不会重传

**其他**

- 目标目录可自由设置，默认 `图片\手机相册`
- 中文相册名、中文文件名正常处理
- 高 DPI 屏幕适配（125% / 150% 缩放不会糊也不会溢出）

## 快速开始

### 1. 下载

到 [Releases](../../releases) 页面下载 `PhoneAlbum-v1.0.0-win64.zip`，解压到任意目录。

> ⚠️ 不要解压到 `C:\Program Files` 这类需要管理员权限的位置。

### 2. 手机上打开 USB 调试（一次性操作）

1. 设置 → 关于手机 → 连续点击「版本号」7 次，直到提示已进入开发者模式
2. 设置 → 系统和更新 → **开发人员选项** → 打开「**USB 调试**」
3. 插上数据线，手机通知栏选择「**传输文件**」
4. 手机会弹「允许 USB 调试吗」→ 勾选「始终允许」→ 点允许

### 3. 运行

双击 `PhoneAlbum.exe`。

左侧出现相册列表就说明连上了。

## 常见问题

### 提示「没检测到手机」

按顺序排查：

1. **换一根数据线**。很多 Type-C 线只能充电，不传数据。
2. 确认手机通知栏选的是「**传输文件**」，不是「仅充电」或「传输照片」。
3. 确认电脑上 `adb devices` 能列出设备（`platform-tools\adb.exe devices`）。
4. 如果 `adb devices` 是空的，但设备管理器里能看到「ADB Interface」在正常状态 —— 双击 **`修复ADB连接.bat`**（需要管理员权限），它会补上 Windows 通用 WinUSB 驱动缺失的 adb 接口 GUID。修复后重开程序。

### 手机一直不弹授权窗口

拔插一次数据线；或在开发者选项里点「撤销 USB 调试授权」，然后重新插。

### 能不能不插线（无线）？

暂不支持。无线 ADB 在华为等机型上不支持稳定，配对流程也跨机型不统一。

### 微信聊天里的图片看不到

聊天记录里的原图在 App 私有目录（`Android/data/com.tencent.mm/`），系统媒体索引不收录。
在聊天里长按图片 →「保存到手机」，之后就会出现在 `Pictures/WeChat` 相册里。

### 传输速度是多少？

实测（华为 P60 Pro，USB 2.0）：

| 场景 | 速度 |
|---|---|
| 批量照片 | 约 35 MB/s |
| 单个大视频 | 37.5 MB/s |

已经吃满 USB 2.0 的理论带宽（约 300 Mbps）。

## 技术细节

- **C# 5 + WinForms**，用 Windows 自带的 `csc.exe` 编译，不需要装 .NET SDK
- 运行时需要 **.NET Framework 4.8**（Windows 10 1903+ 与 Windows 11 均自带）
- 数据来源：`adb shell content query --uri content://media/external/{images,video}/media`
- 传输方式：`adb pull`（批量调用，摊薄进程开销）
- 打包内附 `platform-tools` 的 adb

### 从源码编译

```
src\build.bat
```

需要 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（Windows 自带）。

## 已知边界

工具只读取**共享存储中的媒体索引**，所以看不到：

- App 私有目录（`/data/data/`）里的任何文件
- 带 `.nomedia` 标记的目录
- 未保存到相册的聊天图片
- 非媒体文件（文档、压缩包等）

需要访问这些，请用 `adb shell` 或文件管理器类工具。
